🗄️

O Array (numeros = [])

Imagine uma gaveteira com várias gavetas. Ela começa 100% vazia. Cada gaveta tem uma numeração (índice), começando sempre na gaveta 0.

📝

A variável (let num)

É como uma folha de rascunho temporária. O usuário diz um número, você anota nele rapidamente antes de guardar na gaveta certa.

📥

O método (numeros.push)

É a ação física de empurrar um novo objeto na próxima gaveta livre do final da gaveteira.

🤖

O Loop (for)

É um robô obediente que repete a mesma tarefa quantas vezes você mandar: primeiro para guardar 10 vezes, depois para ler de trás para frente.

📖 Explicação Detalhada do Código

Etapa 1: Abertura

1. Inicializando a Gaveteira Vazia

let numeros = [];

Aqui você cria uma lista na memória do computador. Os colchetes [] vazios indicam que ela ainda não tem nenhum número guardado.

Etapa 2: Preenchimento (Entrada de Dados)

2. O primeiro laço "for" (0 até 9 = 10 vezes)

for (let i = 0; i < 10; i++) {
    let num = Number(prompt("Digite o número para a posição " + (i + 1) + ": "));
    numeros.push(num);
}

Esse bloco repete 10 vezes o mesmo processo:

  • let i = 0: O contador começa em zero.
  • (i + 1): Como o computador conta de 0 a 9, adicionamos 1 apenas para mostrar para o usuário: "Posição 1", "Posição 2", ..., "Posição 10".
  • Number(prompt(...)): O prompt lê tudo como texto. O Number() transforma o texto em número real para cálculos futuros.
  • let num: Guarda esse número digitado temporariamente.
  • numeros.push(num): Pega o valor de num e coloca dentro do array.
❓ Dúvida Comum: "Por que não posso colocar direto sem o .push(num)?" Se você só fizesse let num = prompt(...) sem o push, na volta seguinte do loop a variável num seria apagada e substituída pelo novo número. O .push() é quem garante que o número fique salvo na lista!
Etapa 3: Exibição Inversa (Saída de Dados)

3. O segundo laço "for" (De trás para frente)

for (let i = numeros.length - 1; i >= 0; i--) {
    console.log(numeros[i]);
}

Aqui está o segredo da ordem inversa:

  • numeros.length - 1: O array tem 10 itens no total, mas as posições vão de 0 a 9. Logo, o último item está no índice 10 - 1 = 9. O i começa em 9!
  • i >= 0: O laço continua funcionando até chegar no primeiro elemento (índice 0).
  • i--: Em vez de somar, nós subtraímos 1 a cada volta (9, 8, 7, 6, 5, 4, 3, 2, 1, 0).
  • numeros[i]: Abre a gaveta i e mostra o valor que está lá dentro.

💡 Perguntas Rápidas para Fixar

🔢 Por que arrays começam no índice 0?

Na ciência da computação, o índice representa o deslocamento (distância) a partir do início da memória. O primeiro item está a 0 posições do início.

🔄 Qual a diferença entre i++ e i--?

i++ adiciona 1 (anda para a frente: 0, 1, 2...). i-- retira 1 (anda de ré: 9, 8, 7...).

📏 Por que length - 1 e não apenas length?

Se o array tem 10 elementos, numeros.length vale 10. Se você tentar acessar numeros[10], dará undefined, pois as gavetas vão só até a 9!

📦 Daria para fazer sem a variável "let num"?

Sim! Poderia ser: numeros.push(Number(prompt(...))). Criar a variável num é apenas uma boa prática para quem está aprendendo ler com mais calma.
