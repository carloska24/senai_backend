# Diretrizes de Estilo de Código (Clean Code para Aluno Exemplar)

1. **Estilo de Aluno Destaque**:
   - Códigos limpos, diretos, elegantes e de fácil leitura para professores e colegas.
   - Estrutura organizada e com foco no aprendizado de alto nível.

2. **Nomes de Variáveis Expressivos (Clean Code)**:
   - Utilizar sempre nomes claros, intuitivos e autoexplicativos em português (ex: `contador`, `limite`, `salarioBruto`, `valorImposto`, `percentualDesconto`).
   - Evitar siglas confusas ou abreviações de uma única letra (como `x`, `c`, `n`, `tmp`).

3. **Clareza de Estruturas**:
   - Lógica bem encadeada e simples.
   - Separação clara entre Entrada de Dados, Processamento/Decisão/Laço e Saída de Dados.
