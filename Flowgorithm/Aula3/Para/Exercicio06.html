Exercício 06 - Calculadora de Fatorial Simples

Enunciado: Peça um número e calcule o fatorial dele (ex: 5! = 5 x 4 x 3 x 2 x 1 = 120).

📋 Passos Lógicos

  • 1. Declaração: Ler o número inserido.
  • 2. Loop PARA (For):
    • Inicializa fatorial = 1
    • Para i de 1 até número.
    • Faz fatorial = fatorial * i.
  • 3. Saída: Exibe toda a conta, ex: 5! = 5 x 4 x 3 x 2 x 1 = 120.
