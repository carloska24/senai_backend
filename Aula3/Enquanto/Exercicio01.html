Exercício 01 - Validação de Senha (ENQUANTO)

Enunciado: Crie um algoritmo que peça ao usuário para digitar a senha correta (1234). O sistema deve continuar pedindo a senha até que o usuário acerte.

🔑 Teste de Login

Aguardando envio da senha...

📋 Passos no Flowgorithm

  • 1. Declaração: Criar variável senhaInformada do tipo Inteiro.
  • 2. Saída: Exibir "Digite a senha de acesso:".
  • 3. Entrada: Ler valor para senhaInformada.
  • 4. Estrutura ENQUANTO (While):
    • Condição: senhaInformada != 1234
    • Bloco Interno:
        • Saída: Exibir "Senha incorreta! Tente novamente:"
        • Entrada: Ler novamente para senhaInformada
  • 5. Saída Final: Exibir "Acesso concedido! Senha correta.".
