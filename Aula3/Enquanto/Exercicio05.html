Exercício 05 - Contagem Regressiva até 0

Enunciado: Crie um algoritmo que leia um número inteiro informado pelo usuário e faça uma contagem regressiva até 0, utilizando a estrutura ENQUANTO.

🧪 Simulador de Execução

Digite o número inicial e clique no botão...

📋 Passos no Flowgorithm

  • 1. Declaração: Criar variáveis numeroInicial e contador do tipo Inteiro.
  • 2. Saída: Exibir "Digite um número inteiro para iniciar a contagem regressiva:".
  • 3. Entrada: Ler valor para numeroInicial.
  • 4. Atribuição: Definir contador = numeroInicial.
  • 5. Estrutura ENQUANTO (While):
    • Condição: contador >= 0
    • Bloco Interno:
        • Saída: Exibir contador
        • Atribuição: contador = contador - 1
  • 6. Saída Final: Exibir "Contagem regressiva finalizada!".
