Exercício Desafio - Soma de Números Pares e Ímpares (1 a 100)

Enunciado: Crie um algoritmo que utilize a estrutura de repetição ENQUANTO para percorrer todos os números de 1 até 100. Durante a execução, o algoritmo deve verificar se cada número é par ou ímpar. Os números pares devem ser somados em uma variável específica, e os ímpares em outra. Ao final, apresente a soma dos pares e a soma dos ímpares.

🏆 Simulador de Execução

Soma dos Números Pares
2 + 4 + 6 + ... + 100
-
Soma dos Números Ímpares
1 + 3 + 5 + ... + 99
-

📋 Passos no Flowgorithm

  • 1. Declaração: Criar variáveis contador, somaPares e somaImpares do tipo Inteiro.
  • 2. Inicialização: Definir somaPares = 0, somaImpares = 0 e contador = 1.
  • 3. Estrutura ENQUANTO (While):
    • Condição: contador <= 100
    • Decisão (Se): contador % 2 == 0
        • SIM: somaPares = somaPares + contador
        • NÃO: somaImpares = somaImpares + contador
    • Incremento: contador = contador + 1
  • 4. Saída Final: Exibir somaPares e somaImpares.
