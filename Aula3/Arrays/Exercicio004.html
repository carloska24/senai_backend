🔄 Utilizando Apenas 2 Laços PARA (Zero IF/ELSE)

Exercício 004 - Maior e Menor Valor no Vetor

Enunciado: Desenvolva um algoritmo que leia 10 números inteiros, armazene em um vetor e identifique o maior e o menor valor utilizando apenas laços PARA, sem nenhum bloco condicional (SE/SENÃO).

🔍 Testar Algoritmo

Aguardando digitação dos números...
📌 Estrutura Exata dos 2 Laços PARA:
• 1º PARA (i = 0 até 9): Faz a leitura dos 10 números no vetor.
• 2º PARA (i = 1 até 9): Calcula diretamente o maior e menor sem nenhum bloco SE/SENÃO.
• maior = (maior + vetor[i] + Abs(maior - vetor[i])) / 2
• menor = (menor + vetor[i] - Abs(menor - vetor[i])) / 2

📋 Estrutura no Flowgorithm

  • 1. Declaração: vetor[10], maior, menor e i.
  • 2. 1º Laço PARA (i = 0 até 9): Entrada de dados para cada posição vetor[i].
  • 3. Atribuição Inicial: maior = vetor[0] e menor = vetor[0].
  • 4. 2º Laço PARA (i = 1 até 9): Atualização direta de maior e menor com a função Abs().
  • 5. Saída: Exibição final de maior e menor.
