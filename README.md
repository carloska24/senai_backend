## 📚 Conteúdo dos Módulos

### 🔷 Aula 1: Fundamentos de Lógica e Fluxogramas
- Introdução ao pensamento computacional e algoritmos.
- Entrada, processamento e saída de dados.
- Resolução de problemas utilizando o **Flowgorithm** (`.fprg`).
- Exercícios práticos (01 ao 14) e desafios de lógica.

### 🔶 Aula 2: Estruturas de Decisão e Lógica Proposicional
- **Estruturas de Decisão Simples e Compostas:** Aplicação de condicionais (`Se ... Então ... Senão`).
- **Estruturas Encadeadas:** Resolução de problemas com múltiplas condições correlacionadas.
- **Desafio - Sistema de Aprovação de Empréstimo:** Algoritmo complexo com análises encadeadas de idade, renda mensal, score de crédito e limites dinâmicos (`Desafio_Emprestimo.fprg` e `Desafio_Emprestimo.html`).
- **Implementação Web:** Conversão de algoritmos para **HTML5** e **JavaScript**.

## 🚀 Como Executar os Arquivos

### 1. Arquivos de Fluxograma (`.fprg`)
1. Baixe e instale o [Flowgorithm](http://www.flowgorithm.com/).
2. Abra o software Flowgorithm.
3. Acesse `Arquivo > Abrir` e selecione qualquer exercício `.fprg` dentro das pastas `Aula1/` ou `Aula2/`.
4. Clique no botão **Executar (Play)** para simular o algoritmo.

### 2. Arquivos Web (`.html`)
1. Navegue até a pasta `Aula2/Aula02 - Estrutura de decisao Encadeada/`.
2. Dê um duplo clique em qualquer arquivo `.html` (ex: `Exercicio01.html`) para abri-lo no seu navegador de preferência.

## 📤 Passo a Passo: Como Subir para o GitHub

Siga estas instruções simples para publicar toda a pasta no seu GitHub:

### Passo 1: Criar o Repositório no GitHub
1. Acesse seu [GitHub](https://github.com/) e clique no botão **`+`** (no canto superior direito) > **`New repository`**.
2. No campo **Repository name**, digite um nome como `curso-backend-senai`.
3. Mantenha desmarcadas as opções de adicionar README, `.gitignore` ou licença.
4. Clique em **`Create repository`**.

### Passo 2: Inicializar e Enviar via Terminal (PowerShell / Git Bash)
Abra o terminal na pasta do projeto e execute os comandos:

```bash
# 1. Inicializar o repositório Git local
git init

# 2. Adicionar todos os arquivos para o commit
git add .

# 3. Salvar o primeiro commit
git commit -m "feat: adiciona exercicios e estrutura das Aulas 1 e 2 do curso SENAI"

# 4. Definir a branch principal como main
git branch -M main

# 5. Adicionar a URL do seu repositório do GitHub
git remote add origin https://github.com/carloska24/senai_backend.git

# 6. Enviar para o GitHub
git push -u origin main
```
