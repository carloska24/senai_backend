## 👋 Sobre este Repositório

Repositório de estudos do curso de **Desenvolvedor Backend** da **Escola SENAI "Dr. Celso Charuri"**. Aqui estão documentados todos os exercícios, algoritmos e atividades práticas — do pensamento computacional ao desenvolvimento de sistemas completos.

Cada módulo conta com dois formatos de entrega:

- 📐 **`.fprg`** — Fluxograma interativo no **Flowgorithm**, representando o algoritmo visualmente.
- 🌐 **`.html`** — Implementação web com **HTML5**, **CSS3** e **JavaScript**, simulando o algoritmo em tempo real no navegador.

## 📚 Conteúdo dos Módulos

<details>
<summary><strong>🔷 Aula 1 — Fundamentos de Lógica e Algoritmos</strong></summary>
<br/>

Introdução ao pensamento computacional utilizando o **Flowgorithm**. Construção e leitura de fluxogramas, manipulação de variáveis, operadores e estruturas de entrada/saída.

- Variáveis, tipos de dados e operadores
- Entrada, processamento e saída de dados
- Algoritmos sequenciais
- Resolução de problemas do mundo real com lógica formal
- **Desafios** de lógica com múltiplas variáveis

</details>

<details>
<summary><strong>🔶 Aula 2 — Estruturas de Decisão</strong></summary>
<br/>

Aplicação de condicionais para controlar o fluxo de execução dos algoritmos, em três níveis de complexidade:

- **Decisão Simples:** `Se ... Então`
- **Decisão Composta:** `Se ... Então ... Senão`
- **Decisão Encadeada:** múltiplas condições correlacionadas
- **🏆 Desafio — Sistema de Aprovação de Empréstimo:** análise encadeada de idade, renda mensal, score de crédito e limites dinâmicos (`Desafio_Emprestimo.fprg` + interface web completa `.html`)

</details>

<details>
<summary><strong>🔁 Aula 3 — Estruturas de Repetição</strong></summary>
<br/>

Domínio das três estruturas de laço com exercícios progressivos e desafio final em cada módulo:

| Estrutura | Característica | Pasta |
|:---|:---|:---|
| **PARA** | Número de iterações definido | `Aula3/Para/` |
| **ENQUANTO** | Verifica condição antes de executar | `Aula3/Enquanto/` |
| **FAÇA...ENQUANTO** | Executa ao menos uma vez | `Aula3/Faca/` |

</details>

<details>
<summary><strong>📦 Aula 3 — Arrays: Vetores e Matrizes</strong></summary>
<br/>

Estruturas de dados indexadas para armazenar e manipular coleções de valores. Todos os exercícios utilizam laços `Para` para percorrer os vetores.

| Exercício | Objetivo |
|:---|:---|
| **Exercicio01** | Leitura de 10 inteiros e exibição na ordem inversa |
| **Exercicio02** | Soma de todos os 8 elementos de um vetor |
| **Exercicio03** | Cálculo da média das notas de 5 alunos |
| **Exercicio04** | Identificação do maior e menor valor em 10 elementos |
| **Exercicio05** | Contagem de números pares e ímpares em um vetor |
| **🏆 Desafio** | Ordenação crescente de vetor com 10 inteiros (Exchange Sort) |

</details>

## 🚀 Como Executar

### Arquivos `.fprg` — Fluxograma (Flowgorithm)

1. Baixe e instale o [Flowgorithm](http://www.flowgorithm.com/).
2. Abra o software e acesse `Arquivo > Abrir`.
3. Selecione qualquer arquivo `.fprg` dentro das pastas `Aula1/`, `Aula2/` ou `Aula3/`.
4. Clique em **Executar (▶)** para simular o algoritmo passo a passo.

### Arquivos `.html` — Interface Web Interativa

1. Navegue até a pasta desejada (ex: `Aula3/Arrays/`).
2. Dê um duplo clique em qualquer arquivo `.html` (ex: `Exercicio01.html`).
3. O exercício abrirá no seu navegador com formulário interativo, passos do algoritmo e representação visual do fluxograma.

### Clonar o Repositório

```bash
git clone https://github.com/carloska24/senai_backend.git
cd senai_backend
```
